# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 1.7.x   | Yes       |
| < 1.7   | No        |

Security fixes go into the latest 1.7.x release of the LabTether Windows agent.

## Report a vulnerability

Please report security problems privately. Do not open a public issue.

- Preferred: [GitHub private vulnerability reporting](https://github.com/labtether/labtether-win/security/advisories/new)
- Or email [support@labtether.com](mailto:support@labtether.com)

Tell us the app version (shown in About), your Windows version, what you
found, and how to reproduce it. Do not send tokens, passwords or other
secrets.

We will confirm we received your report, keep you updated while we fix it, and
credit you in the release notes if you want.
